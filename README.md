# Titanic-Survival-Analysis

📌 Overview

This project performs exploratory data analysis (EDA) on the Titanic passenger dataset to understand the factors that influenced survival. The analysis focuses on data cleaning, feature understanding, and visualization to extract meaningful insights from structured data.

The goal is to analyze patterns related to passenger demographics and travel class rather than building predictive models.

📂 Dataset

The dataset contains passenger information such as:

Age

Gender

Passenger class

Fare

Survival status

It is a widely used dataset for practicing data analysis and visualization techniques.

🔍 Analysis Performed

Data loading and initial inspection

Handling missing values and data cleaning

Exploratory analysis of survival trends based on:

Gender

Passenger class

Age distribution

Fare

Visualization of insights using plots and charts

Documentation of findings within a Jupyter Notebook

📊 Tools & Technologies

Python

Pandas

NumPy

Matplotlib

Seaborn

Jupyter Notebook

🎯 Key Insights

Survival rates varied significantly based on gender and passenger class

Certain age groups had higher survival probabilities

Fare and class showed strong correlation with survival outcomes
